### Requirments:
- RP2040 Zero
- TEMT6000

### Wiring method:
- 26: Signal
- 27 or GND: Ground
- 28 or 3v3: VCC


Since https://github.com/thariq-shanavas/RP2040_USBHID_Ambient-Light-Sensor did not work on my PC, I created this project by using that repository as a reference.
